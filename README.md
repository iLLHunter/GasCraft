# Gascraft 1.0.5

Gas production machines, canisters, grenades, a grenade launcher and protective equipment for Minecraft. Includes smoke, chemical agents and gases with effects on players and mobs.

**Minecraft 1.21.1 · NeoForge 21.1.243 or newer · Java 21**

Install Gascraft on the server and every player client. Curios, JEI and Mekanism are optional integrations.

Craft a **Gascraft Manual** from a **Book + Grenade Diffuser** for illustrated recipes, machine instructions and gas effects in 22 languages. Modpack content may differ from the manual.

Settings are in `config/gascraft/`. Server owners and pack makers can disable individual gas chains and customize agents, gases and recipes through JSON definitions. Example files are generated automatically; [`gascraft.api`](src/main/java/gascraft/api) provides mod integration hooks.

[Download on CurseForge](https://www.curseforge.com/minecraft/mc-mods/gascraft) · [Changelog](CHANGELOG.md) · [Report an issue](https://github.com/iLLHunter/GasCraft/issues) · [LGPL-3.0-only license](LICENSE)

```powershell
.\gradlew.bat build --no-configuration-cache
```
